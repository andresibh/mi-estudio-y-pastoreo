# Mi Estudio y Pastoreo — sincronización privada

Aplicación en español para temas, subtemas, textos, enlaces, notas y bosquejos. Permite preparar contenido en computadora y consultarlo desde iPhone/iPad con la misma cuenta.

**Estado: código preparado; requiere activar Supabase.** Empieza por [CONFIGURAR.md](CONFIGURAR.md). No reemplaces tu web actual hasta completar la configuración y exportar tus datos anteriores.

Incluye inicio de sesión, guardado automático, acceso por propietario con RLS, copia local de cambios pendientes, detección de conflictos e importación de la biblioteca anterior. Conserva exportación/importación JSON.

No es una aplicación oficial de jw.org ni JW Library.
