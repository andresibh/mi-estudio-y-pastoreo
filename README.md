# Mi Estudio y Pastoreo
Aplicación web personal en español para organizar temas, subtemas, textos bíblicos, enlaces y bosquejos.

## Publicación gratuita con GitHub Pages
1. Crea un repositorio público, por ejemplo `mi-estudio-pastoreo`.
2. Sube `index.html`, `manifest.webmanifest`, `icon.svg` y `sw.js` a la raíz.
3. Abre **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Selecciona **main** y **/(root)** y pulsa **Save**.
5. Espera a que GitHub muestre la dirección HTTPS publicada.
6. Abre esa dirección en Safari (iPhone/iPad), pulsa Compartir → Añadir a pantalla de inicio.

## Privacidad y limitaciones
Los datos se guardan solo en el almacenamiento local del navegador en cada dispositivo. GitHub Pages publica el código, pero no tus notas guardadas localmente. No hay cuenta, sincronización ni cifrado de notas. Exporta copias de seguridad con frecuencia. No guardes información confidencial sobre personas. Para compartir enlaces desde otras apps, pega la URL en «Añadir referencia»; la integración nativa con el menú Compartir queda para una versión futura.
